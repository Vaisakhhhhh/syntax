# Syntax

A modern, highly customizable rich text editor built using React, Tiptap, and Tailwind CSS. 

## Features

- **Built with React & TypeScript:** Robust, type-safe development.
- **Tiptap Editor:** A powerful, headless rich text framework for React.
- **Tailwind CSS Styling:** Utilizing `@tailwindcss/typography` for beautiful prose styling.
- **Lucide Icons:** Clean and consistent iconography via `lucide-react`.
- **Vite:** Fast development server and optimized build process.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate into the project directory:
   ```bash
   cd syntax
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

To start the development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

### Building for Production

To build the application for production:

```bash
npm run build
```

This will run TypeScript type checking and then build the Vite project into the `dist` directory. You can preview the build using:

```bash
npm run preview
```
